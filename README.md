# 飞书电子表格 图片导出 / 回传

**Author: YX&Grok**

从飞书电子表格批量下载单元格图片，本地处理后（例如 4K 超分）再按文件名写回原单元格。

脚本文件：`feishu_sheet_images.py`

---

## 功能

| 菜单 | 作用 |
|------|------|
| `[1] 导出` | 读取指定工作表、指定列里的嵌入图片，保存到本地 |
| `[2] 回传` | 按文件名把本地图片写回对应单元格（会覆盖原图） |

导出支持：

- 多工作表、多图片列
- 4 种命名方式（行_列 / 自定义列 / 人物表 / 场景表）
- 场景视角后缀：正 / 侧 / 背 / 俯 / 仰 / 低
- 超大表格自动分块读取（避免飞书 10MB 限制）
- 下载中途 **P** 暂停/继续，**Q** 结束

---

## 环境

- Windows 10/11
- Python 3.12+（安装时勾选 **Add python.exe to PATH**）
- 依赖：`requests`

安装依赖：

    py -m pip install requests

把 `feishu_sheet_images.py` 放到任意目录，例如 `D:\user\下载\`，然后：

    cd /d D:\user\下载
    py feishu_sheet_images.py

## 获取 Token（必读）

打开 [飞书 API 调试台](https://open.feishu.cn/api-explorer)

1. 右上角登录你的飞书账号
2. Authorization **选 `user_access_token`，不要选 `tenant_access_token`**
3. 点「获取 Token」
4. 复制 **`u-` 开头** 的字符串，粘贴进脚本

说明：

- `u-`：你本人身份。能打开、能编辑的表，导出和回传都用这个
- `t-`：应用身份。列表或许能读，**回传几乎一定报 `99991672 No permission`**
- Token 大约 **2 小时过期**，过期回调试台重新获取
- 应用需开通「查看、评论、编辑和管理电子表格」，并发布版本；改权限后必须重新获取 Token

## 推荐工作流（4K 处理后写回）

1. 运行脚本，选 **`[1] 导出`**
2. 粘贴 `u-` Token 和表格链接
3. 选择工作表和图片列（人设一般是 `H`，场景一般是 `I,J,K,L…`）
4. 命名选 **`[1] 行_列`**，例如 `3_8.png` = 第 3 行 H 列。这样回传位置最准
5. 本地做 4K 处理，**不要改文件名**
6. 再运行脚本，选 **`[2] 回传`**
7. 指到处理好的文件夹，映射方式选 **`[1] 行_列`**

若导出时用了人物/场景中文名（`3_林悦_漂亮就行.png`），回传请选 **`[2]`**，并指定写回哪一列（人设一般是 `H`）。

## 导出说明

启动后按提示填写：

1. Token
2. 表格链接（脚本会自动抽出 token）。例：`https://xxx.feishu.cn/sheets/P7YDsNAKDhhmcKtwRuEceqiDnoe`
3. 保存目录（请填完整路径，如 `D:\user\下载\人设图`；回车则保存在脚本旁的 `feishu_images`）
4. 工作表（`1,3` 或回车=全部）
5. 图片列（如 `H,I`）
6. 命名方式

每个工作表会建一个子文件夹。下完后会尝试打开资源管理器。

### 命名方式

| 选项 | 文件名示例 | 适用 |
|------|------------|------|
| `[1] 行_列` | `3_8.png` | **准备回传时推荐** |
| `[2] 自定义` | `3_林悦_漂亮就行.png` | 自选若干文字列，可加视角后缀 |
| `[3] 人物表` | `3_林悦_漂亮就行.png` | 自动找「角色」「备注」；备注只取第一个「，」前；无备注不加 `_` |
| `[4] 场景表` | `2_将军府主卧.png` / `5_将军府书房_正.png` | 自动找「场地名称」；「图」列不加后缀，正面平视→`_正` 等 |

同一单元格多张图会追加 `_2`、`_3`。

## 回传说明

- 必须使用 **`u-` Token**
- 会 **覆盖** 目标单元格原图
- 接口支持 png / jpg / jpeg / gif / bmp / tiff 等，**不支持 webp**
- 单张十几 MB 的 PNG 可能失败或极慢。分辨率 4K 可以保留，建议转成 **高质量 JPG（90–95）**，体积通常小很多，像素不变

文件名映射：

| 选项 | 规则 |
|------|------|
| `[1]` | `行_列.扩展名`，如 `10_8.png` → H10 |
| `[2]` | `行号_任意文字`，全部写入你指定的同一列 |

## 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `python` / `pip` 不是内部命令 | 没装 Python，或没用 PATH | 从 python.org 安装并勾选 Add to PATH；用 `py` 启动 |
| `python xxx.py` 无输出 | 指向商店占位 `WindowsApps\python.exe` | 关掉「应用执行别名」里的 python.exe，重装官方 Python |
| 找不到 `.py` 文件 | 记事本存成了 `.txt` | 资源管理器勾选「文件扩展名」，改名为 `.py` |
| `99991672 No permission` | 用了 `t-` Token，或应用没有编辑权限 | 改用 `u-`；应用开通编辑表格并发布后重新取 Token |
| `90221 data exceeded 10485760 bytes` | 一次读的范围太大 | 脚本已自动拆分；若仍出现会再对半切 |
| 回传全部 400，body 不对 | 旧版脚本把图当成 base64 | 请用整合版（`image` 为字节数组） |
| 搜协作者找不到应用 | 应用未发布/未安装到组织 | 回传不必加应用为协作者，用 `u-` 即可 |
| 大图回传失败 / 很慢 | JSON 传字节数组体积膨胀 | 转 JPG、保持文件名再传 |

## 权限清单（应用后台）

开发者后台 → 应用 → 权限管理，建议开通：

- 查看、评论、编辑和管理电子表格
- 查看、评论和导出电子表格
- 下载云文档中的图片和附件
- 上传图片到云文档（如有）

开通后 **创建版本并发布**，再回调试台重新获取 `user_access_token`。
